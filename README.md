# 📖 小说创作助手 (Novel Assistant)

> **版本：v3.2** ｜ 基于 **PySide6** 的桌面端 AI 小说创作工具
> 本地优先 · 数据自有 · AI 驱动的全流程写作助手

一款集**大纲管理、角色设定、伏笔追踪、设定库、AI 对话生成、一键导出**于一体的桌面写作软件。
所有创作数据以 Markdown + JSON 形式存储在本地项目目录，**完全由您掌控**，不依赖任何云服务。

- ✅ **本地优先**：所有数据为纯 Markdown / JSON，可直接用编辑器打开、可用 Git 版本管理

- ✅ **AI 工具调用**：AI 可主动读取大纲/角色/设定/伏笔数据，并执行增删改操作
- ✅ **跨线程安全**：AI 流式输出与日志推送均通过 Qt Signal 桥接，UI 不冻结

## 快速开始

### 环境要求

- **Python 3.10+**（推荐 3.11 / 3.12）
- **Windows**（开发与测试主要在 Windows 上进行；脚本为 `.bat`）
- 需要一个兼容 **OpenAI 接口协议**的 AI 服务（如 DeepSeek、OpenAI 等）

### 安装步骤

**方式一：使用安装脚本（推荐）**

```bat
:: 1. 双击运行，自动创建虚拟环境并安装依赖
setup_env.bat

:: 2. 启动应用
run_app.bat
```

**方式二：手动安装**

```bat
:: 创建虚拟环境（统一使用 .venv）
python -m venv .venv

:: 激活环境
.venv\Scripts\activate.bat

:: 安装依赖
pip install -r requirements.txt

:: 启动
python app.py
```

### 依赖清单

```
openai>=1.50.0        # AI 接口调用（OpenAI 兼容协议）
cryptography>=41.0.0  # API Key 加密存储
PySide6>=6.6          # Qt6 GUI 框架
pytest>=8.0.0         # 测试框架
pytest-mock>=3.12.0   # 测试 Mock
```

### 首次使用

1. 启动后进入 **🔧 配置** 面板；
2. 填写 AI 源的 **名称 / Base URL / 模型名 / API Key**；
3. 点击**保存**（API Key 会自动加密存储）；
4. 切换到 **💬 对话** 面板开始创作。

## 核心写作流程

### 1. 创建项目

启动后若没有项目，应用会提示创建。所有项目存放于 `workspace/projects/` 下，一个项目一个文件夹。

### 2. 搭建大纲（📖 大纲面板）

大纲采用**五级结构**：

| 层级 | 含义 | 说明 |
|:----:|------|------|
| 1 | 大纲 | 全书总纲 |
| 2 | 卷 | 分卷 |
| 3 | 简纲 | 卷内剧情梗概 |
| 4 | 章纲 | 单章梗概 |
| 5 | 正文 | 实际章节内容 |

**主要操作**（通过界面按钮完成，不依赖快捷键）：

- **新建 / 重命名 / 删除** 节点
- **⬆ 升级 / ⬇ 降级**：调整节点层级
- **▲ 上移 / ▼ 下移**：同级排序
- **更改父节点**：移动到其他节点下（自动防止形成循环）
- **合并**：将多个同级节点合并为一个（自动汇总正文）
- **三栏编辑**：左侧大纲树 / 中间子节点列表 / 右侧内容编辑器

> 📝 正文编辑器支持 Markdown，并**实时统计字数**。

### 3. 建立角色（👤 角色面板）

- 填写**姓名、性别、年龄、生日**等基础字段
- 编写 **Markdown 角色简介**（外貌、性格、背景、成长弧线…）
- 关联**阵营**（可多选），支持快速添加/移除关联
- 支持按阵营筛选角色

### 4. 埋设伏笔（🔮 伏笔面板）

- 记录伏笔内容、所属章节、状态（未回收 / 已回收）
- 支持隐藏/显示、按序号排列
- 便于写作时检查"还有哪些坑没填"

### 5. AI 辅助创作（💬 对话面板）

这是核心生产力工具。AI **可以直接读取和修改您的项目数据**：

```
您：请读取大纲的第 3 卷内容和相关角色，帮我写第 12 章的开头，800 字左右，
    注意主角的性格要和角色设定一致。

AI：（自动调用工具读取大纲 + 角色数据）→ 生成正文 → 可直接写入大纲节点
```

**AI 面板功能**

- **流式输出**：文字逐字显示，实时可见
- **深度思考**：支持 reasoning 模型的思考过程展示（可开关）
- **停止生成**：随时点击 ⏹ 中断，已生成内容会保留
- **自动续写**：输出被 `max_tokens` 截断时自动续写（可配置轮数）
- **工具调用**：AI 自动批量读取项目数据，并按需增删改
- **发送快捷键**：`Ctrl + Enter`

### 6. 查看进度（📊 状态面板）

- 展示项目统计：大纲节点数、正文章节数、完成数、总字数
- 点击生成按钮，**AI 会根据当前进度输出针对性创作建议**（模板可在配置中自定义）

### 7. 导出成果（📤 导出面板）

- 左侧为**复选树**，可按需勾选要导出的内容：

```
📖 大纲       （可选具体章节）
👤 角色
⚙ 设定
🔮 伏笔
📋 日志
```

- 右侧选择**输出目录**与格式：
  - ☑ **合并为单个 Markdown 文件** — 全部内容合并为一个 `.md`
  - ☐ 不勾选 — 按类型分文件输出
  - 日志格式可选 `.txt` / `.md`
- 点击 **🚀 开始导出** 即可

## AI 能力说明

### 工具调用机制

启用工具后，AI 会在对话中**自主决定**读取或修改项目数据：

| 工具类别 | 能力 |
|---------|------|
| **统一读取** | 一次性批量读取大纲 / 设定 / 角色 / 伏笔，避免多次往返 |
| **大纲操作** | 创建节点、更新内容、查询树结构 |
| **角色操作** | 新增/修改角色、关联阵营 |
| **伏笔操作** | 新增/更新/删除伏笔条目 |
| **设定操作** | 读写设定文档 |

- **最大工具轮数**可在配置中调整（默认 5，范围受配置约束）
- AI 的工作流由 **功能提示词**（`chat_skill_text`）引导，可在配置面板中自定义

### 深度思考与自动续写

| 功能 | 说明 |
|------|------|
| **深度思考** | 针对支持 reasoning 的模型，展示思考过程并可累积到后续轮次 |
| **自动续写** | 输出达到 `max_tokens` 上限时，自动追加请求继续生成剩余部分 |

### AI 源管理

- 支持配置**多个 AI 源**，随时切换
- 每个源可独立设置：`Base URL`、`模型名`、`备用模型`、`temperature`、`top_p`、`max_tokens`
- API Key **加密存储**，重命名 AI 源时密钥会自动迁移，不会丢失

## 常见问题（FAQ）

**Q1：支持哪些 AI 服务？**
只要兼容 **OpenAI 接口协议**即可，例如 DeepSeek、OpenAI、Ollama（本地）等。在配置面板填写对应的 Base URL 与模型名即可。

**Q2：API Key 安全吗？**
安全。Key 使用 `cryptography` 加密后存入 `key_store.db`，不会以明文出现在配置文件或日志中。

**Q3：数据存在哪里？会上传云端吗？**
不上传。所有数据存于本地 `workspace/projects/` 目录，格式为纯 Markdown + JSON。只有调用 AI 时才会把相关内容发送给您配置的 AI 服务商。

**Q4：AI 生成的正文会自动保存吗？**
AI 通过**工具调用**写入数据时会即时保存到项目文件。纯对话内容保存在 `workspace/sessions/` 会话记录中。

**Q5：可以中断 AI 生成吗？**
可以。生成过程中点击 **⏹ 停止生成**，已生成的部分会保留，不会丢失。

**Q6：如何备份项目？**
直接复制 `workspace/projects/<项目名>/` 整个文件夹即可。也可以对整个 `workspace/` 目录使用 Git 进行版本管理。

**Q7：启动报错"未找到虚拟环境"？**
先运行 `setup_env.bat` 创建环境。注意虚拟环境目录名为 `.venv`（`run_app.bat` 同时兼容 `venv` 与 `.venv`）。

**Q8：文字输出被截断了？**
这是达到 `max_tokens` 上限。可在配置中**调大 `max_tokens`**，或开启**自动续写**让 AI 自动补全剩余内容。

**Q9：切换面板或编辑角色时感觉卡顿？**
v3.2 已针对角色模块做性能优化（索引缓存、消除重复读盘、列表增量刷新）。若仍有明显卡顿，请检查项目内角色数量并反馈。

**Q10：日志在哪里看？**
应用内 **📋 日志** 面板可查看（支持按级别/模块过滤，自动收集最近 5 个日志文件）；原始文件位于 `workspace/logs/`。

### 架构设计

**三层架构 + 事件驱动**

```
┌─────────────────────────────────────────────┐
│   UI 层 (src/ui)                            │
│   面板继承 BasePanel，通过 EventBus 订阅数据变更 │
└──────────────┬──────────────────────────────┘
               │ 调用 / 订阅事件
┌──────────────▼──────────────────────────────┐
│   服务层 (src/services)                      │
│   ProjectService（含 Character/Foreshadow 子服务）│
│   AIClient · SessionManager · ToolRegistry   │
└──────────────┬──────────────────────────────┘
               │ 读写 / 记日志
┌──────────────▼──────────────────────────────┐
│   核心层 (src/core)                          │
│   ConfigManager · EventBus · Logger          │
└─────────────────────────────────────────────┘
```

**关键设计约定**

1. **事件总线是同步的**：`EventBus.publish()` 在**调用线程**直接执行订阅者的回调。
   > ⚠️ **重要**：禁止在订阅回调中直接操作 Qt 控件。AI 与日志均在**后台线程**发布事件，必须通过 **Qt Signal** 桥接到主线程后再更新 UI（参见 `log_panel.py` 的 `log_received` 信号）。

2. **服务层与 UI 解耦**：UI 不直接读写文件，一律通过 `ProjectService` 及其子服务。

3. **数据类**：`Character`、`Camp`、`OutlineNode`、`Foreshadow` 等使用 `@dataclass`。

4. **懒加载子服务**：`ProjectService.character_service` / `foreshadow_service` 按需创建，并在切换项目时重置。

5. **性能注意事项**：
   - `CharacterService` 对 `index.json` / 阵营文件做了 **mtime 失效缓存**，重复调用不重复读盘
   - 角色的 `birthday` / `age` 存于索引，避免逐个读取 `data.json`（消除 N+1 I/O）
   - 外部直接修改文件后，mtime 变化会自动使缓存失效

### 事件清单

| 事件名 | 触发时机 |
|--------|---------|
| `project:switched` | 切换项目 |
| `outline:tree_changed` | 大纲树结构变更 |
| `chapter:saved` | 章节正文保存 |
| `character:created` / `updated` / `deleted` | 角色增删改 |
| `camp:created` / `updated` / `deleted` | 阵营增删改 |
| `foreshadow:created` / `updated` / `deleted` | 伏笔增删改 |
| `setting:updated` | 设定增删改 |
| `config:changed` | 配置变更 |
| `ai:response_start` / `chunk` / `end` / `error` | AI 流式响应生命周期 |
| `log:new` | 新日志产生（供日志面板实时展示） |

- 📤 **独立导出面板**：统合大纲/角色/设定/伏笔/日志导出，支持勾选与合并输出
- 🔐 **API Key 加密机制重构**：改用持久化稳定标识文件派生密钥，彻底解决环境变化导致 Key 无法解密的问题

**修复**
- 修复日志面板实时推送失效的问题（新增 `log:new` 事件 + 跨线程信号桥接）
- 修复状态面板统计信息始终显示"加载中"的问题
- 修复导出面板事件订阅名称不匹配导致树不刷新的问题
- 修复大纲面板「升级/降级/移动/合并」调用不存在的方法导致的崩溃
- 修复「停止生成」按钮无效的问题（新增 AI 请求取消机制）
- 修复配置面板重命名 AI 源导致 API Key 丢失的问题

**优化**
- ⚡ **角色模块性能优化**：索引缓存 + 消除 N+1 读盘（读盘次数 31 → 1），列表增量刷新，切换/编辑不再卡顿
- 统一虚拟环境目录为 `.venv`，启动脚本自动兼容 `venv` / `.venv`
- 统一版本号为 `3.2.0`
