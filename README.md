## 1. 快速开始 — 5 分钟上手

### 第一步：安装环境

双击项目中的 `setup_env.bat`，脚本会自动完成虚拟环境创建和依赖安装。

### 第二步：启动应用

双击 `run_app.bat`，应用窗口打开后，你会在左侧看到 8 个导航按钮。

### 第三步：配置 AI

点击左侧 **🔧 配置**，切换到配置面板：

```
1. 填写 AI 源信息：
   - 名称：给它起个名字，如 "我的 OpenAI"
   - Base URL：API 地址（如 https://api.openai.com/v1）
   - API Key：你的密钥（会自动加密存储，不会泄露）
   - 模型：如 gpt-4o-mini

2. 点击「🔌 测试连接」确认可用
3. 点击「💾 保存」
```

连接成功，你就可以开始创作了！

### 第四步：创建项目

点击左侧 **📖 大纲**，切换到纲面板：

1. 在下拉框右侧点 `[+新项目]`（或直接在下拉框输入项目名后回车）
2. 给你的小说起个名字，比如"星辰之巅"
3. 系统会自动创建一个"全书大纲"根节点

### 第五步：开始对话

点击左侧 **💬 对话**，在底部输入框输入你的第一个问题：

> "帮我为玄幻小说《星辰之巅》构思一个开篇"

AI 会流式逐字回复，你就能获得第一份创作灵感了！

## 3. 创作流程 — 从灵感到正文

软件提供了一套 **5 级大纲体系**，帮你从宏观到微观逐步构建小说：

```
全书大纲 (L1)
  └─ 第一卷·星辰陨落 (L2 卷纲)
       ├─ 开篇·主角觉醒 (L3 简纲，覆盖10~20章)
       │    ├─ 第1-3章·废材逆袭 (L4 章纲，覆盖3~6章)
       │    └─ 第4-6章·初入宗门 (L4 章纲)
       └─ 中段·宗门试炼 (L3 简纲)
```

### 在大纲面板中操作

**创建节点**：选中父节点 → 点 `[+ 新建]` → 输入标题

**编辑内容**：选中节点 → 右侧 Markdown 编辑器自由写作

**让 AI 帮忙**：选中节点 → 点 `[🤖 AI生成]` → 配置生成数量 → AI 批量生成子节点

**改变结构**：
- `⬆ 升级` / `⬇ 降级`：改变节点层级
- `▲ 上移` / `▼ 下移`：调整同级顺序
- 右键 → "更改父节点"：移动到其他节点下

**追踪进度**：点击标题旁的状态指示器，在 ○待开始 / ●进行中 / ✓已完成 / ⊘忽略 之间切换

### 快捷操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存当前编辑 |
| `Ctrl+N` | 新建子节点 |
| `Ctrl+R` | 重命名节点 |
| `Delete` | 删除节点 |
| `Ctrl+↑↓` | 同级排序 |
| `Ctrl+←→` | 升级/降级 |

## 4. 角色管理 — 构建你的人物群像

> **核心理念**：角色是独立的个体，阵营（门派/势力/组织）是可以独立创建和管理的标签。

### 创建角色

点击 **👤 角色** → 点 `[+ 新角色]` → 输入角色名（如"林风"）

### 填写角色信息

选中角色后，你看到三个区域：

```
┌──────────────┬──────────────────┬────────────────────────┐
│ 角色列表      │ 基本信息          │ 角色简介 (Markdown)     │
│              │                  │                        │
│ ● 林风        │ 名称: 林风        │ # 林风                  │
│              │ 性别: 男          │                        │
│              │ 生日: 玄历三百年   │ 青云宗外门弟子，自幼     │
│              │ 年龄: 18          │ 父母双亡...             │
│              │                  │                        │
│              │ 阵营: [青云宗] ×   │                        │
└──────────────┴──────────────────┴────────────────────────┘
```

- **左侧**：基本信息（名称/性别/生日/年龄），修改后点 `💾 保存`
- **右侧**：角色简介，用 Markdown 自由书写（支持标题、列表、加粗等），修改后点 `💾 保存简介`

### 管理阵营（门派/势力）

点角色面板顶部的 `[🏷 管理阵营]`：

1. 输入阵营名称和简介 → 点"新建/更新"
2. 创建后会自动关联到当前选中的角色
3. 一个角色可以拥有**多个阵营标签**（如"玄机子"同时属于"青云宗"和"散修联盟"）
4. 点击阵营标签上的 **×** 即可移除关联

> 💡 **与设定面板的关系**：角色面板侧重结构化管理和 AI 标签关联；设定面板中保留了"角色设定"分类，你可以写更详细的角色文档。两者互为补充，可以根据需要手动或让 AI 来同步。

## 5. 伏笔管理 — 埋线与回收

> 伏笔是散布在故事中等待回收的线索。软件帮你记录和追踪它们，AI 也能看到你的伏笔，在续写时帮你自然回收。

### 添加伏笔

点击 **🔮 伏笔** → 在底部输入框写下伏笔内容 → 点 `[+ 添加]`

```
示例：
  "第一章中主角捡到的玉佩实为上古神器，将在后期觉醒"
  "神秘老者的真实身份是主角的祖父"
  "第三章提及的预言将在第七卷应验"
```

### 隐藏伏笔（节省 Token）

有些伏笔你可能不想让 AI 过早知道（比如涉及剧透的）：

- 右键伏笔 → 选「隐藏/显示」
- 隐藏的伏笔**不会**上传给 AI（节省 token）
- 切换回显示后，AI 又能看到它了

### 与 AI 对话的集成

当你在💬对话面板和 AI 交流时，未隐藏的伏笔会自动作为上下文发送给 AI。AI 看到伏笔后，会在续写时自然地铺垫和回收这些线索。

## 6. 创作状态 — AI 帮你把握全局

### 查看基础统计

点击 **📊 状态**，你会看到当前项目的基本数据：

```
📊 基本信息
   当前项目: 星辰之巅
   总大纲节点: 24
   已完成节点: 8
   L5 正文章节数: 14
   总字数: 128,500
```

### AI 一键生成创作状态

点击 `[🤖 AI 一键生成创作状态]`：

1. 系统会**弹出确认对话框**，提示此操作会消耗较多 token（会把大纲 L1~L4 + 角色 + 设定 + 伏笔都上传给 AI）
2. 确认后，AI 会分析你的创作数据，生成一份结构化的状态摘要，包括：
   - 📖 整体进度概览
   - 📈 各故事线分析
   - 👤 角色使用情况
   - 🔮 伏笔回收状态
   - 💡 创作建议

> ⚠️ 此功能会消耗大量 token，建议在创作到一定规模后偶尔使用，不要频繁调用。

## 7. 进阶技巧

### 7.1 AI 对话中的内容勾选

在💬对话面板的**右侧**有一个可折叠的内容勾选面板：

- 勾选你想让 AI 参考的大纲节点和设定文档
- 发送消息时，AI 会按照**消息 → 创作状态 → 伏笔 → 勾选内容**的顺序理解上下文
- AI 优先理解你的意图，其次了解当前创作进度，然后关注伏笔线索，最后参考已有内容

### 7.2 使用提示词

对话面板顶部有两个提示词区域：

- **系统提示词**（始终生效）：定义 AI 的角色，如"你是一位专业的小说创作助手，擅长玄幻、奇幻类型的创作..."
- **附加提示词**（需勾选启用）：临时指令，如"请用古风文笔回复"、"请用轻松幽默的语气"

可以保存多组提示词，随时切换。

### 7.3 AI 工具调用

对话面板顶部有 `[🔧 AI工具: ✓]` 开关。启用后，AI 可以：

- 直接读取你的大纲节点和设定文档
- 帮你创建新章节
- 帮你保存设定内容
- 搜索已有内容

你可以在💬对话中直接对 AI 说："帮我把这个新设定保存到力量体系分类中"，AI 会自动调用工具完成操作。

### 7.4 多 AI 源切换

在🔧配置面板中，你可以保存多组 AI 源配置（如 OpenAI、本地 Ollama、硅基流动等）。选中想使用的 AI 源，点击「✅ 设为当前」即可切换。

### 7.5 设定导出

在⚙设定面板中，点击 `[📤导出]`，可以将选定范围的设定导出为 Markdown 文件，方便分享或备份。

## 8. 常见问题

### Q: 数据存储在哪里？会丢失吗？

所有数据存储在 `workspace/` 目录下。每个项目独立存储（JSON + Markdown），关闭重启后数据不会丢失。建议定期备份整个 `workspace/` 目录。

### Q: API Key 安全吗？

API Key 使用 AES-256 加密存储在 SQLite 数据库中，不会以明文出现在任何配置文件中。

### Q: 角色面板和设定面板里的"角色设定"有什么区别？

| | 角色面板 | 设定面板·角色设定 |
|------|---------|-----------------|
| 侧重点 | 结构化字段 + 阵营标签 + AI 上下文 | 自由格式 Markdown 文档 |
| 用途 | 快速查找、AI 标签关联 | 详细的角色深度设定 |
| 关联 | 数据自动参与 AI 对话上下文 | 需要手动勾选才会送给 AI |

两者**互补**，你可以把角色面板当作"人物速查卡"，设定面板当作"人物深度档案"。

### Q: 伏笔为什么要隐藏？

当你不想让 AI"提前知道"某个伏笔时——比如涉及大结局的关键线索，你希望 AI 在写前面章节时不被剧透——就把它隐藏。之后回收伏笔时再取消隐藏，AI 就能看到并帮你回收了。

### Q: AI 工具调用安全吗？

AI 工具只能读写当前项目的数据，不会访问其他项目或系统文件。你随时可以关闭工具开关，AI 就只会对话而不会操作数据。

### Q: 日志面板为什么以前看不到日志？

这是 v2.0 修复的 bug。之前日志面板只显示启动后的新日志，现在会自动加载当天的历史日志文件。如果仍看不到，尝试清空级别筛选或点击"🔄 刷新"。
